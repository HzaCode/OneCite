### Why is OneCite awesome?

OneCite is a universal citation and academic reference toolkit that automates bibliography management for researchers and developers. It has been:

- ✅ **Recognized by the community**: Featured in [awesome-LaTeX](https://github.com/egeerardyn/awesome-LaTeX#bibliography-tools)
- ✅ **Actively used**: Published on PyPI with active downloads
- ✅ **Well-maintained**: MIT licensed, comprehensive documentation, and regular updates
- ✅ **Model Context Protocol support**: Integrated with MCP client, editor client and other MCP clients

### Key Features

- 🔍 **Smart Recognition**: Accepts DOI, arXiv ID, PMID, ISBN, GitHub URLs, or plain text queries
- 📚 **Multiple Output Formats**: BibTeX, APA, and MLA
- 🎯 **High Accuracy**: 4-stage processing pipeline (clean → query → validate → format)
- 🌐 **9+ Data Sources**: CrossRef, Semantic Scholar, PubMed, arXiv, dblp, DataCite, Zenodo, OpenAlex, Google Books
- 🤖 **MCP Integration**: Full MCP support for MCP clients
- 🎓 **7+ Citation Types**: Journal articles, conference papers, books, software, datasets, theses, preprints

### Links
