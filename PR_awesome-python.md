### Description
Add **OneCite** to the appropriate category. OneCite is a powerful Python library and CLI tool for automated citation management.

### What is OneCite?
OneCite is a universal citation and academic reference toolkit that automates the tedious process of bibliography management. It supports:
- 🔍 Smart recognition from DOI, arXiv, PMID, ISBN, or plain text
- 📚 Multiple output formats (BibTeX, APA, MLA)
- 🎯 High-accuracy 4-stage processing pipeline
- 🤖 MCP client integration via Model Context Protocol (MCP)
- 🌐 Data from 9+ academic databases (CrossRef, Semantic Scholar, PubMed, arXiv, etc.)
